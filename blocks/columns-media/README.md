# columns-media

Custom **columns** block. Purpose: image-text-split.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Reverse (copy left, image right) | `reverse` |
| Panel (with `reverse`: grey copy panel + full-height image, two columns on mobile too) | `panel` |
| Steps (ordered list as a dotted vertical timeline, full-height image) | `steps` |
| Numbered (with `steps`: white numbered discs on a red rail, boxed; text + list rows) | `numbered` |
| Filled (with `steps`: dark-red filled numbered discs overlapping the image; image hidden on mobile) | `filled` |
