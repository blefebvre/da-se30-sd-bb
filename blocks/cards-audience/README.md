# cards-audience

Custom **cards** block. Purpose: audience-selector.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell of content.

## Supported variations

| Variation | Option class |
| --- | --- |
| Landscape | `landscape` |
| Compact | `compact` |
| Promo | `promo` |

### Promo

Two full-bleed photo tiles (50/50 above 1080px, stacked below) with
left-aligned, bottom-anchored copy: heading, short text, and a link in its own
paragraph rendered as a red pill button. Only the button is clickable.

Rows: `[picture | h3 + p + p>a]`.
